# tuning-lab

Applicazione web per esplorare i sistemi di intonazione musicali con la Web Audio API, partendo dal sistema pitagorico.

## Funzionalità iniziali

- tastiera di pianoforte interattiva con riproduzione immediata delle note
- preset di intonazione per confrontare sistema pitagorico e temperamento equabile
- riproduzione di scale in salita e discesa, più un accordo semplice
- editor delle frequenze delle note con aggiornamento diretto del suono
- ripristino del preset corrente per tornare ai valori originali

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build di produzione

```bash
npm run build
```
